# INTRODUÇÃO A JAVA
## 1.1 O que é JAVA
Java é uma linguagem de programação inventada em 1995 pela Sun Microsystems. Java é baseada em classes e programação orientada a objetos. Java é uma linguagem rentável, seguro e confiável. Há diversos cursos e informações para e dá linguagem por ser uma linguagem de programação muito usada no mercado — pelos códigos legados — e por conta de ser segura, logo que seu conteúdo é verboso. Java está sendo usado por grandes empresas como Netflix, Amazon, Spotify e o Banco do Brasil, também presente nos celulares Android, Video Games e Supercomputadores científicos. Um dos jogos que mais usa essa linguagem é Minecraft, tendo a versão Java e Bedrock, essa feita em C++.

## 1.2 - Características da linguagem JAVA
Características principeis da linguagem Java:
- **Portabilidade**: Java é uma linguagem de programação que pode ser executada em qualquer lugar.
- **Segurança**: Java é uma linguagem de programação que é segura e confiável
- **Rendimento**: Java é uma linguagem de programação que é rentável e eficiente
- **Objetos**: Java é uma linguagem de programação que é baseada em classes e orientada a objetos.

## 1.3 - Tipos de variáveis em JAVA
- **Variáveis Int**: São usadas para armazenar números inteiros.
- **Variáveis Float**: São usadas para armazenar números decimais.
- **Variáveis String**: São usadas para armazenar strings de texto.
- **Variáveis Boolean**: São usadas para armazenar valores lógicos (true ou false)
